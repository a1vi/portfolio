# MD. Atair Rahman Alvi — Engineering Portfolio

An interactive portfolio designed in the visual language of *Metaphor: ReFantazio*: a launch screen, a rotating wheel of hand-lettered words, and dedicated quest and codex screens for engineering milestones.

## Highlights
- **Electrical & Electronic Engineering (B.Sc. at BRAC University, CGPA: 3.52/4.00)**
- **VLSI & Physical Design**: RTL-to-GDSII flow and automated timing closure grid-search framework for OpenLane / OpenROAD on SkyWater 130 nm PDK.
- **Autonomous UAV & Robotics**: Capstone project **Firehawk**, an autonomous firefighting drone with multi-sensor payload and fire-extinguishing ball deployment.
- **Publications & Research**: Peer-reviewed paper published in **IEEE ICCIT 2025** on CNN-based satellite image classification for deforestation detection in Dhaka.
- **Industry Experience**: Associate Project Manager Intern at **Excelerate** driving remote agile delivery and task coordination.

## Screens
- **Journey**: Educational milestones (BRAC University EEE, HSC, SSC).
- **Projects (Quests)**: 10 flagship and side engineering quests (Firehawk Drone, OpenLane Parameter Sweep, CNN Accelerator ASIC, ML PPA Optimization, Proteus Elevator, CubeSat Payload, Gas Leakage Alarm, Buck-Boost PI Converter).
- **Abilities**: Programming, VLSI EDA, Embedded IoT, Machine Learning, and Engineering Tools.
- **Experience (Chronicle)**: Industry and research roles.
- **Research**: OpenLane timing closure treatise, benchmark slacks, and IEEE ICCIT publications.
- **Creative / Artifacts**: Hardware, silicon layouts, and autonomous systems showcase.
- **About**: Character profile, ledger stats, and verified links.
- **Contact**: Direct interactive dispatch and verified social profiles.
- **Settings**: Audio, cursor, and motion accessibility preferences.

## Stack
- React 18 · TypeScript · Vite · Framer Motion
- Deployed via GitHub Actions to GitHub Pages.
